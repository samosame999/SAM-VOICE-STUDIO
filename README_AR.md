# دليل تشغيل SAM VOICE STUDIO — الإصدار 3.0 الفائق 🎙️

منصة هندسة الصوت واستنساخ البصمات الصوتية بالذكاء الاصطناعي مع المطابقة الصارمة للوقت.

## المميزات الجديدة في الإصدار 3.0
1. **الدمج الذكي الثلاثي (Ultra-Human Fusion):**
   - **Chatterbox Engine:** لإضفاء التنفس الطبيعي ومحاكاة الحبال الصوتية البشرية والقضاء على الآلية والرتابة.
   - **Qwen-TTS Prosody:** لتحليل سياق النص والمشاعر وتعدد اللهجات العربية والإنجليزية.
   - **Fish Audio Timbre:** لتنقية العينة المرجعية واستنساخ خامة الصوت العاطفية بدقة فائقة.
2. **المطابقة الزمنية الصارمة (15s - 60s):**
   - التزام دقيق بأجزاء من الثانية دون تسريع كرتوني أو تشويه الحبال الصوتية.
3. **مؤثرات صدى الاستوديو (Studio Echo & Reverb):**
   - سلايدر تحكم مرن من 0% حتى 100% مع إمكانية التفعيل والإلغاء الفوري.
4. **اكتشاف فوري لأي صوت جديد:**
   - ضع أي ملف صوتي داخل مجلد `voices` ليتعرف عليه البرنامج ويتحدث به فوراً.

## متطلبات التشغيل
- نظام Windows 10 أو 11
- بطاقة رسوميات NVIDIA (يفضل مع دعم CUDA) أو العمل بوضع المعالج المركزي CPU
- بيئة Python 3.11 المدمجة

## طريقة التشغيل المباشر
1. شغل `run_windows.bat` أو الملف التنفيذي المباشر `SAM_VOICE_STUDIO.exe`.
2. افتح المتصفح على العنوان: `http://127.0.0.1:8765`.
