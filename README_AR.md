# SAM VOICE STUDIO — Starter 0.1

## ما الذي يعمل الآن؟
- واجهة محلية في المتصفح.
- مربع كتابة عربي/إنجليزي.
- اختيار اللغة.
- شريط مدة مرن من 5 إلى 180 ثانية، مع أزرار 15/30/60.
- عدّ الكلمات وتقدير مدة القراءة لحظياً.
- واجهة مكتبة أصوات أولية.
- واجهة تصدير WAV/MP3 (تفعيل التوليد ينتظر اختيار محرك صوت مناسب).

## المتطلبات
- Windows 10/11
- Python 3.11
- VS Code
- تعريف NVIDIA حديث (لفحص البطاقة)

## التشغيل
1. فك ضغط المجلد.
2. افتح المجلد في VS Code.
3. شغّل `check_gpu.bat` لمعرفة اسم البطاقة والذاكرة.
4. شغّل `run_windows.bat`.
5. افتح `http://127.0.0.1:8765`.

## تنبيه مهم حول محرك الصوت
XTTS-v2 يدعم العربية والإنجليزية واستنساخ الصوت عبر اللغات، لكنه مرخّص بترخيص Coqui Public Model License ذي قيود على الاستخدام التجاري ومخرجاته. لذلك لم أضعه كمحرك افتراضي قبل تحديد ما إذا كان الاستخدام شخصياً أم تجارياً ومراجعة الترخيص. راجع الترخيص الأصلي قبل أي استخدام: https://huggingface.co/coqui/XTTS-v2

## الخطوة التالية
أرسل ناتج `check_gpu.bat`، وحدد أن لديك إذناً صريحاً من أصحاب التسجيلات لاستنساخ أصواتهم. بعد ذلك نختار محركاً محلياً متوافقاً مع GTX 1660 وترخيصه يناسب طريقة استخدامك.
